Sheets & Calendar sync

Sambungkan semua modul ke Google Sheets supaya data tersimpan permanen dan bisa diakses dari mana saja. Setup satu kali, berlaku untuk semua modul.

1
Buat Google Sheets master
Buka sheets.google.com → buat spreadsheet baru → beri nama WG88 Operations Hub. Buat sheet tab: Orders, Customers, StokSekarang, History, RekapBulanan, Vouchers, VoucherKlaim.
2
Paste Apps Script
Di Sheets → Extensions → Apps Script → hapus kode lama → paste kode ini → Save.
3
Deploy sebagai Web App
Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy → copy URL.
4
Masukkan URL Web App
5
Test koneksi
☆
Google Calendar (target pengiriman)
Setelah Sheets tersambung, setiap Fix Order dengan tanggal kirim akan otomatis ditambahkan ke Google Calendar kamu. Pastikan scope calendar sudah diizinkan saat authorize Apps Script.

Sync manual sekarang

Kirim semua data yang tersimpan di browser ke Google Sheets sekaligus.
